ÄNDERUNG: Delta-Modus (--delta Flag)
  Datei: scripts/import_trades.py
  Grund: Wöchentlicher Quiver-Download hat nur ~200-500 neue Trades.
         Full Rebuild (2-3h) ist Overkill — Delta braucht ~1-2 Minuten.

  Neue Methoden:
  - _create_dup_key(df) → pd.Series (String-Key pro Zeile fuer Vergleich)
  - detect_new_trades(input_df, master_df) → DataFrame mit nur neuen Trades
  - run_delta() → kompletter Delta-Workflow

  Delta-Workflow (run_delta):
  [1/5] Lade neue Quiver-CSV (alle Trades)
  [2/5] Lade bestehende trades_master.csv
  [3/5] Key-Vergleich → finde neue Trades (DUPLICATE_CHECK_COLUMNS aus settings.py)
  [4/5] Enrichment nur fuer neue Trades
  [5/5] Vote-Timing nur fuer neue Trades
  → Append an trades_master.csv (pd.concat)

  Dedup-Key: name|ticker|asset_name|transaction_type|amount|transaction_date|subholding|comment
  (Nutzt DUPLICATE_CHECK_COLUMNS aus settings.py — war bereits vorhanden)

  CLI:
  - python scripts/import_trades.py           # Full Rebuild (wie bisher)
  - python scripts/import_trades.py --delta   # Nur neue Trades

  Neue Imports: argparse, pickle
